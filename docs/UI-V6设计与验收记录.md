# 珞珈生化智能体 UI V6 设计与验收记录

## 视觉依据

- 武汉大学公开标识规范：珞珈蓝 RGB(0,37,84)、珞珈绿 RGB(17,87,64)，辅助色克制使用珞樱粉和东湖蓝。
- 老图书馆作为校徽核心地标；产品使用原创水彩剪影，不下载、裁切或拼贴官网照片和参考截图。
- 学生端保留“轻量实验探险册”语义；教师端使用浅色专业工作台，不使用闯关卡通视觉。

## 原创资产

| 文件 | 用途 | 体积目标 |
|---|---|---|
| `public/illustrations/luojia-biochem-agent-bg-v1.webp` | 首页原创水彩背景 | 小于 500KB |
| `public/illustrations/login-luojia-poster-v1.webp` | 登录静态首帧和降级背景 | 小于 500KB |

生成提示方向：武汉大学老图书馆/老斋舍的非写实水彩剪影，与 DNA、蛋白带状结构、细胞、烧杯和试管构成分层课程氛围；无文字、无徽标、无人像、留出内容安全区。视频由同一原创画面做缓慢循环位移，不使用第三方视频。

## 固定视觉变量

- 字体：`Noto Sans CJK SC` → `Source Han Sans SC` → `Microsoft YaHei` → `PingFang SC`。
- 移动正文不小于 14px；辅助标签最小 10px，只用于状态和元数据。
- 主操作 52px，普通触控目标最小 48×48px。
- 圆角：12/18/28px；页面水平安全区手机 12–18px。
- 所有动画只使用 opacity/transform；省流量、`prefers-reduced-motion` 或视频失败时保持静态海报。

## 验收清单

- [ ] 360×800：统一首页、登录、八步地图、步骤、报告无横向滚动。
- [ ] 390×844：固定底栏不遮挡输入和提交，软键盘后仍可操作。
- [ ] 768px：学生与教师页面布局不裁切。
- [ ] 1366×768、1440×900：首页信息层级和教师数据密度合理。
- [ ] 学生无教师切换和教师 API 权限；教师学习体验明确提示不计成绩/同步。
- [ ] 内容草稿、完整性校验、发布、成绩异议与复核按钮可用。
- [ ] 登录视频失败、减少动画和省流量状态均显示静态海报。
- [ ] 新版截图保存到 `docs/evidence/v6-*`，并记录浏览器验证结果。

# 水彩课堂交互与验收（2026-09-05）

本次沿用现有模型、八步地图及课程内容，不新增生产表和运行时 DDL。以下“浏览器通过”仅指明确注明的环境，不代表全部生产业务已验收。

## 组件与交互契约

- `TaskPrinciples`：目标、原理、器材识别和操作自检。自检四类内容统一展开/收起；器材只使用课程真实图片。
- `QuizPanel`：答题、刚提交、历史回顾使用同一题卡。优先恢复进行中记录，其次最近已批改答卷；点击“练习新题”才请求新测验。历史按批次分页选择，已有完成资格不因练习新题撤销。
- `ExperimentWriter`：目录 → 单环节多行输入 → 整份方案检查 → 统一评阅。提示围绕目的、顺序、参数、器材、观察和判断，填写不等于掌握。空段定位，失败保留草稿。
- `StepReviewReport` / `StudyReport`：概况、五维雷达、逐项证据、改进资料。八步切换而非堆叠；完整参考和改写答案受结束状态限制，分数使用 `computeGradeSummary`。
- 教师学生列表与异议列表使用同一 `Sheet`，移动端全宽、桌面右侧抽屉，可跳独立档案。复核读取正式 `requestId`，确认与调分动作符合接口约束。

## 接口说明

| 接口 | 契约 |
|---|---|
| `GET /api/student/quiz/history?stepNo=1&page=0` | 每页10条本人 graded 摘要；返回 items/nextPage/activeId/hasCompleted，不返回题目答案 |
| `GET /api/student/quiz/session?session_id=...` | 本人会话题干、完整选项、草稿、状态及 stepNo；仅 graded 返回 results |
| `PATCH /api/student/quiz/session` | `{session_id,answers}`；校验本人、in_progress、真实题号及选项，状态变化返回409 |
| `POST /api/student/quiz/start` | 只抽教师发布的本人未做题；不足一批提示暂时没有更多新题，不清除历史或声称全题库完成 |
| `POST /api/student/quiz/submit` | 全部作答且最终确认后批改；条件更新阻止重复提交，不允许覆盖已批改答卷 |

客户端类型与白名单位于 `src/lib/quiz-contract.ts`。`submitted` 不等于 `graded`，不能凭“非进行中”泄露答案。所有查询的 user_id 来自服务端登录身份，不接受客户端指定身份。

文字草稿保存在当前浏览器 localStorage，以会话 UUID + 步骤隔离（`ljbio-description-v2`）；不跨设备同步，清理浏览器数据会丢失未提交草稿。服务器已提交文字优先作为恢复基线，本机后续修改覆盖草稿。阶段位置同范围保存。测验选项保存在服务端既有 `quiz_sessions.answers`；预览仅使用 sessionStorage 演示数据，不能当生产证据。

## 实际验证记录

- `pnpm validate`：类型检查与 ESLint 通过。
- `pnpm test`：77项通过，含答案白名单、submitted 不泄露、草稿选项校验、重进序列化、教师授权班级服务模拟测试。
- `pnpm exec next build`：生产构建通过，48页生成完成。构建生成声明不提交。
- 本地真实浏览器、预览数据：逐题选择保存、刷新恢复、最终确认前无答案、提交后重进同题卡、进入文字推演；空方案定位、五段草稿恢复、整合与预览评阅；教师抽屉 Esc/移动全宽/档案跳转/预览复核。
- 报告在390/768/1440宽度切换四个分区，无水平溢出；八步原理均检查器材页和四类自检统一展开/收起。
- 截图在忽略目录 `output/playwright/`；浏览器脚本 `scripts/qa-*.cjs` 由 `pnpm dlx @playwright/cli -s=classroom run-code --filename scripts/qa-xxx.cjs` 执行。先启用本地 UI preview 并在3010端口启动；classroom/writer 脚本要求分别处于初次测验和文字推演页。脚本不写生产数据。

## 未验收与素材缺口

- 当前没有两个学生、两个教师及两个班级的独立生产登录条件，生产跨班越权、提示注入、真实教师复核新增报告版本仍需这些身份完成验收。服务模拟测试不能替代真实 RLS/OAuth 验收。
- 真手机软键盘、触控及系统缩放没有物理设备验收；已检查浏览器移动视口和文档流底栏。
- 真实 AI 评阅失败重试、模型图片输入及报告内容质量不是本次预览评阅的覆盖范围，不能据此声称网关实测通过。
- 器材图：当前匹配超声破碎仪、低温离心机、分光光度计、酶标仪。步骤1/2/5/6/7暂缺匹配实物图；步骤3/4/8也只覆盖已有器材，不代表全部器材素材齐全。待补PCR仪、电泳/成像系统、金属浴、生物安全柜、摇床、层析/pH/透析/转膜等课程授权图片。
- 教师原始材料与现行清单对照见《教师需求与八步功能验收清单》；未取得原始材料逐段审定证据的条目不能标为“原文全部达标”。

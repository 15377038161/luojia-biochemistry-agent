# 超星任务流网页桥接与可靠同步

## 当前接入结论

本项目使用两层同步，不能把浏览器消息发送等同于数据库写入成功：

1. 正式学生提交先写入 Supabase，并由 `sync_outbox` 保存可重试事件；这是业务主记录。
2. 当 Coze 网页运行在受信任的超星智能体容器中时，前端按超星页面通信协议调用任务流 `153154`，让任务流向表单 `3513491` 写入步骤评阅或最终学习报告副本。
3. 教师学习体验会话不生成超星任务流载荷，也不进入超星同步。
4. 浏览器桥接没有权威的逐条成功回执，因此只显示“已发送同步请求”；只有服务端正式写入接口和回查接口均通过时，后台健康状态才可标记为“已接通”。

## 已发布的超星任务流契约

- 任务流名称：`写入生物实验评价记录`
- 任务流 ID：`153154`
- 当前已验证发布版本：`v0.0.6`
- 数据源表单 ID：`3513491`
- 初始化参数：`event_id`、`student_id`、`step_id`、`version_no`、`student_answer`、`ai_feedback`、`gate_status`、`total_score`、`ai_confidence`、`teacher_comment`、`final_report`
- 表单字段：除 `event_id` 外的上述业务字段；图片字段目前留空。

## 网页桥接调用

`src/lib/chaoxing-taskflow-client.ts` 仅在页面被超星智能体 iframe 承载且父页面来源位于可信域名白名单时工作。调用顺序：

1. 向父窗口发送 `CXBOT:setWsExtraData`，其中 `taskId=153154`、`chatModel=APP`、`taskInitParams` 为本次评阅载荷。
2. 等待 250ms 后发送隐藏的 `CXBOT:send` 消息，内容为“写入生物实验评价记录”。
3. 顶层运行、非超星来源或伪造来源时不发送任何跨窗口消息，数据仍留在 `sync_outbox`。

可信父页面来源严格限定为超星官方通信说明列出的 `robot.chaoxing.com`、`robot1`、`robot2`、`robot-dev`、`robot-lc`、`robot-lc1`、`robot-lc2`，发送时禁止使用 `*` 作为目标来源。

## 服务端可靠同步配置

浏览器桥接不需要密钥。若超星后续提供正式任务流 HTTP 调用地址或开放 API，再配置服务端传输：

```dotenv
CHAOXING_FORM_ID=3513491
CHAOXING_FORM_TRANSPORT=taskflow
CHAOXING_FORM_WRITE_URL=<超星正式调用地址>
CHAOXING_FORM_WRITE_TOKEN=<仅放在服务端环境变量>
CHAOXING_FORM_READBACK_URL=<正式回查地址>
CHAOXING_FORM_RATE_LIMIT=2
NEXT_PUBLIC_CHAOXING_TASKFLOW_ID=153154
```

未获得正式地址、鉴权和回查契约时，`CHAOXING_FORM_TRANSPORT` 必须保持 `disabled`。禁止把 Cookie、浏览器内部请求或登录态写入配置、Git、日志和交付包。

## 验收步骤

1. 从超星智能体内打开已部署的 Coze 网页，以测试学生身份完成一次文字评阅。
2. 页面应提示“已向超星任务流发送同步请求，服务器队列仍保留可靠留痕”。直接打开 Coze 网页时应提示保留服务器同步队列。
3. 在超星表单管理页按测试学生 ID 查询记录，核对步骤、版本、文字回答、AI 反馈、Gate、总分与置信度。
4. 使用同一 `event_id` 重放服务端请求，确认正式 API/任务流支持幂等；若不支持，需在超星端增加唯一键或任务流查重节点。
5. 只有“写入成功、表单回查一致、重复请求不新增第二条”全部通过，才把正式服务端传输状态改为启用。

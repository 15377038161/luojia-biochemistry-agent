# UI V10「珞珈山小实验家」视觉与验收记录

## 本轮范围

本轮只重构界面呈现，不修改登录、角色识别、八步实验内容、Gate、评分、教师复核和超星同步契约。

已完成：

- 统一入口改为武汉大学品牌色与 EGFP 荧光实验台双栏主视觉。
- 加入武汉大学官方校徽、项目已有学习通图标，并抽成联合品牌组件。
- 学生地图、单步任务、学习报告和教师工作台统一为暖白实验手账语言。
- 加入细胞、烧瓶、试管、实验气泡、珞樱花和分子轨道等低干扰装饰。
- 加入 CSS 光晕、漂浮、冒泡、轨道和路线动画，并支持减少动态效果。
- 修正教师桌面端重复出现移动导航的问题；移动导航保持组件内横向滚动。

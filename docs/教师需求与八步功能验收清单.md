# 教师需求与八步功能验收清单

| 原需求 | 代码入口 | 验收结果 |
|---|---|---|
| 八步骤地图，步骤2与3有桥梁 | `student-map.tsx`、地图底图资源 | 保留八步地图和桥梁，不改回旧地图 |
| 每步三级教学交互与 Gate | `step-workstation.tsx`、`experiment.ts` | 任务原理、知识检验、文字推演、点评报告四阶段；八步均有 Gate |
| SOP参数、安全与设备识别 | `teaching-layers.ts` | 八步均补齐参数、安全、设备与记录要求 |
| 决策树、验证与排错 | `teaching-layers.ts`、`evaluation.ts` | 每步有判断分支；确定性规则限制漏项得分并禁止虚判通过 |
| 科学精神/可复现性 | `teaching-layers.ts` | 每步有科学实践要求，强调对照、留样、可追溯与可复算 |
| AI 认真检查原理、步骤和数据 | `coze-workflows.ts`、`evaluation.ts` | 三维必查清单 + 参数/顺序/异常硬约束；漏项强制 revise |
| 详细参考答案与原理 | `step-learning-report.ts`、报告工作流 | 正式结束后展示底层原理、完整参考答案和基于原文的改写答案 |
| 五维学习报告 | `grading.ts`、`study-report.tsx` | 五个 0–100 维度统一计算，包含失分、短板、建议、证据和复核状态 |
| 报告独立页面 | `/student/report` | 已完成，未在答题中提前泄露完整答案 |
| 单页单题、最终统一批改 | `/api/student/quiz/*`、`step-workstation.tsx` | 最终提交前 API 不返回正确答案或解析；只抽本人未做题 |
| 自选目标基因贯穿八步 | `student_experiment_profiles`、`experiment-profile-card.tsx` | 支持推荐 EGFP、登录号、粘贴 CDS；评测、助教、报告接收会话档案 |
| 教师页面不塞成长页 | `/teacher/*`、`content-manager.tsx` | 概览、列表/抽屉、五分栏学生档案、八步索引和单步五分区编辑 |
| 教师查授权班级，学生不得查同伴 | `teacher-scope.ts`、`teacher-agent.ts`、`tutor.ts` | 教师证据先服务端按班级过滤；学生同伴数据请求不触发模型或数据库查询 |
| 教师终审并保留历史 | `appeals.ts`、`learning_reports` | AI 结果为暂定；复核生成新报告版本，保留消息、复核与事件时间线 |

## 尚需部署环境完成的唯一配置

在 Coze/部署平台服务端 Secret 中设置 `AI_GATEWAY_API_KEY`，然后重新部署。密钥不得写入 `.env.example`、源码、构建日志或 Git。部署后分别对 `qwen3.8-max` 的结构化评测/报告/图片输入和 `deepseek-v4-flash-0731` 的助教/出题做一次真实请求回查。

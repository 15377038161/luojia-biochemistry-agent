# UI V8 统一登录首页验收

## 调整结果

- `/` 同时承担简短产品说明和学习通统一登录，不再先经过介绍页；
- `/login` 只做兼容跳转到 `/`，不渲染第二套登录界面；
- 删除旧 `LoginExperience` 组件；
- 学生与教师身份仍由学习通和服务端权限自动识别；
- 入口页只保留定位、主操作、三项边界说明和一张智能体状态卡。

- 390×844：页面高度等于视口高度，无横向滚动；
- 1440×900：页面高度等于视口高度，无横向滚动；

# UI视觉与交互验收记录

## 1. 产品与视觉基准

- 产品定位：进入实验室前的八步文字推演训练，不执行真实实验，不上传真实实验结果。
- 唯一活动UI：现代科研教学作为整体基调，数字实验手册承载内容，任务地图表达八步进度。
- 视觉语言：深蓝信息层级、生物绿行动状态、暖白阅读面、淡珊瑚纠错提示；不再使用旧版皮革、纸纹、印章和多套原型页面。
- 响应式优先级：学生手机端 → 学生桌面端 → 教师桌面端；教师手机端保证查询与复核可用。
- 页面架构：入口页 → 学生地图 → 独立步骤页 / 独立报告页；教师使用独立工作台。旧预览地址只做跳转，不保留平行界面。
- 主题氛围：CSS 绘制的细胞、细胞核、试管、烧杯和分子贴纸，透明度不超过 24%；仅使用 transform 动画，不新增背景图片或视频请求。

## 3. 真实流程验收

在 `/preview/student/map`、`/preview/student/step/4` 和 `/preview/student/report` 完成以下浏览器流程：

1. 从八步地图进入当前第4步。
2. 阅读任务与原理，完成两道知识检验。
3. 进入五个子步骤的文字推演，一键填入演示描述并显式保存草稿。
4. 在提交前确认Gate页不可进入。
5. 提交AI点评后自动进入Gate页，显示85/100、无安全修正项和Gate通过。
6. 打开学习报告，核对五维标签、八步记录和AI总结。
7. 进入教师端，核对班级统计、学生原文、五维得分和教师复核区。

## 4. 多页面与轻交互验收

- `/preview/student/map` → `/preview/student/step/4` → `/preview/student/report` 均产生真实 URL 跳转，返回地图和返回首页有效。
- 学生端会预取地图、报告和所有已解锁步骤；路由加载态不会出现空白页面。
- 360×800 下流程按钮实测高度均为 48px；步骤页、报告页和教师端 `scrollWidth` 均等于视口宽度。
- 游客抽屉支持关闭按钮、遮罩关闭和向下滑动关闭；首次指引同样支持遮罩和向下滑动关闭。
- 教师端移动导航的“班级概览 / 学生进度 / 复核详情”均可用；点击“复核详情”后目标区停在顶部安全位置。
- 新生产浏览器会话无控制台错误。

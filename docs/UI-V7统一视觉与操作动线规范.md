# UI V7 统一视觉与操作动线规范

## 1. 产品与页面边界

产品名称为“武汉大学生物化学文字实验智能体”，短名称为“珞珈生化智能体”。学生只进行实验前文字推演、案例图分析、AI 点评、修订和 Gate 检查，不进行真实实验操作，也不生成真实实验数据。

活动页面只有一套：

- `/`：精简产品说明与唯一统一身份入口；
- `/login`：兼容旧链接并跳转到 `/`，不单独渲染界面；
- `/student/map`：学生八步路线；
- `/student/step/[stepId]`：当前步骤任务；
- `/student/report`：学习报告；
- `/teacher/dashboard`：教师工作台。

`/preview/*` 只保留开发兼容跳转，实际页面统一落在上述正式路由并使用 `?preview=1`。生产环境必须关闭 `ENABLE_UI_PREVIEW`。

## 2. 核心操作动线

### 学生

`统一登录首页 → 八步地图 → 当前步骤 → 知识检验 → 文字推演 → AI 点评 → Gate → 下一步／报告`

- 根页面在首屏内完成产品说明和身份登录，不再提供介绍页、独立登录页或学生／教师双角色选择。
- 登录后由服务端身份能力决定默认工作区。
- 地图是学生唯一学习总览；已解锁节点可进入，锁定节点只解释解锁条件。
- 步骤页只保留一个顶部页头、一条阶段导航和一个底部操作栏。
- 报告返回地图，避免“首页／地图／报告”多个返回按钮同时竞争。

### 教师

`首页 → 统一登录 → 教学工作台 → 班级概览／学生复核／成绩认定／内容管理／集成状态`

教师可从工作台进入独立学习体验；体验数据不计成绩、不进入班级统计和超星同步。

## 3. 视觉变量

| 用途 | 值 |
| --- | --- |
| 主蓝 | `#123F70` |
| 深蓝文字 | `#082F5D` |
| 生物绿 | `#236F5B` |
| 阶段珊瑚 | `#E87561` |
| 暖白纸张 | `#FFFDF8` |
| 页面底色 | `#F7F4ED` |
| 分隔线 | `#DFE5E4` |
| 辅助文字 | `#667887` |
| 正文 | 手机和桌面均以 `14px` 为基础 |
| 辅助文字 | `12px`，不得承载关键操作 |
| 小／中／大圆角 | `10px / 16px / 22px` |
| 主要触控高度 | 手机不小于 `48px` |

字体固定使用思源黑体／微软雅黑／苹方系统字体栈，不再混用楷体、手写体或不稳定的生成字体。

## 4. 组件规则

- 页头：品牌、可选返回、当前页标题、最多两个右侧动作；手机隐藏文字但保留图标和无障碍名称。
- 主按钮：每个页面或阶段只设置一个最高优先级主按钮。
- 卡片：统一使用 1px 分隔线、16px 圆角和轻阴影；不使用厚皮革边框、线圈、印章堆叠。
- 地图节点：外层命中区域固定；悬浮只抬升内部插画 2px，不改变外层坐标。
- 阶段导航：固定五等分，顺序为任务、检验、推演、点评、Gate。
- 弹窗／抽屉：桌面支持遮罩和 Esc 关闭；移动端保留下滑关闭手势。

## 5. 响应式规则

- `≤767px`：单列内容；地图为纵向路线；底部阶段操作固定在安全区；所有主操作高度不小于 48px。
- `768–1023px`：学生内容保持单列或两列信息卡；教师指标可两列。
- `≥1024px`：地图使用横向双排路线；任务页为主任务区与 AI 反馈双栏；教师端显示固定侧栏。
- 全尺寸必须满足 `scrollWidth === clientWidth`，不得出现横向滚动。

## 6. 动效与可访问性

- 动效只使用 `transform` 和 `opacity`，持续时间 180ms 左右。
- `prefers-reduced-motion` 下关闭节点动画和页面进入动画。
- 焦点状态使用清晰外框；图标按钮必须提供 `aria-label`。
- 地图节点悬浮前后外层 `getBoundingClientRect()` 必须保持一致。

## 7. 验收记录

本轮真实浏览器检查覆盖：首页、登录、地图、步骤、报告与教师工作台；手机基线为 390×844，桌面基线为 1440×900。截图和检查数据保存在 `docs/evidence/ui-v7-audit/`。

正式外部联调仍以校方 OAuth、Supabase、Coze 和超星表单凭据为门禁；UI 预览成功不等于线上集成已经接通。

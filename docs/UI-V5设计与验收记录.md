# UI V5 设计与验收记录

## 产品与视觉边界

- 产品是“进入实验室前的八步文字推演训练”：方案设计、案例图分析、AI 点评、修订与 Gate 通过，不记录或伪造真实实验数据。
- 学生端采用整屏暖白水彩背景、半透明浅纸张卡片、科研蓝和珊瑚红；“实验探险册”是整页的信息层级，不使用厚书脊、线圈或不规则本子边缘。
- 教师端保留相同色彩与纸张质感，但以学生进度、遗漏和复核为主，不加入闯关化视觉。

## 固定移动端规范

| 项目 | 规则 |
| --- | --- |
| 字体 | `Noto Sans CJK SC`、思源黑体、微软雅黑降级链；所有页面一致 |
| 字号 | 辅助 12px、正文 14px、输入 16px、区块标题 20px、页面标题 28px |
| 触控 | 主要操作最小 48px；圆角统一为 10–16px |
| 安全区 | 分步页底部栏固定，并预留 `safe-area-inset-bottom` |
| 动效 | 仅使用 opacity/transform；减少动态偏好下关闭动画 |
| 背景 | `biochem-notebook-watercolor.webp` 在手机端分别置于顶部与底部，正文保持留白可读，不把背景裁切为单张中间卡片 |

## 已验收页面

- 入口页：明确文字实验边界、八步预览、学生与教师入口。
- 学生路线：移动端蜿蜒探索路径、通过／当前／待修订／未解锁状态。
- 八步地图统一为轻量“实验探险册”：暖白水彩背景、薄纸张分层、科研蓝与珊瑚状态色、浅蓝虚线路径和固定无衬线字号。保留可读的步骤插图与完成状态，不使用厚皮革书脊、线圈、手写字体或卡通闯关皮肤。
- 学生分步页：整屏水彩边饰、简洁顶部导航、横向阶段切换、任务情境、理论提示、分阶段文字作答、AI 点评与珊瑚色固定操作栏。
- 学习报告：只展示八步文字推演、Gate 和评阅记录。
- 教师工作台：班级概览、学生八步进度、复核详情；不增加接口外的虚构数据。

## 2026-08-23 系统性可用性优化

- 首页取消首次访问自动弹出的阻断式说明层；产品边界继续以内联文字呈现，学生可以直接查看路线或开始学习。
- 学生步骤页的五阶段导航固定为手机端五等分入口，统一使用“任务、检验、推演、点评、Gate”短标签，不再依赖横向滚动发现后续功能。
- 学生步骤页顶部操作改为固定网格：返回地图、返回首页、Gate 状态和步骤标题互不挤压；底部上一阶段、保存、下一阶段统一 48px 触控高度并预留安全区。
- 教师手机端默认只展示班级概览和学生列表；点击学生或“复核详情”后打开独立全屏详情层，支持关闭按钮和 Esc 返回，避免列表与复核内容组成超长单页。
- 新增统一交互变量：48px 主控件、10/14px 圆角、响应式页面边距、键盘焦点和减少动画偏好。
- 桌面端八步地图高度从大面积留白状态收紧，教师工作台继续保持双栏复核布局，学习报告保持宽屏双列能力分析。
